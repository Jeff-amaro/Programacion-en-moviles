# Lab-integrador-amaro
Fase 1 sin iA


App movil desarrollada en android studio usando el lenguaje de kotlin y jetpack compose, usamos la estructura de MVVM


- Se uso la API del tema productos segun la guía que brindo el profesor, para obtener el catalogo de productos en tiempo real obtenido desde servicios web externos (DummyJSON)


- Para la parte de autenticación y seguridad  se uso (Firebase Auth y Firestore) , para un inicio de sesión seguro y control de roles.


- Las notificaciones locales en el dispositivo al sincronizar catálogos o limpiar la cache local.
