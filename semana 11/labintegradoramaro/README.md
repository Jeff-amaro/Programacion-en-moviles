# Lab-integrador-amaro

- App móvil desarrollada en kotlin utilizando jetpack compose y arquitectura MVVM,  cuenta con autenticación en la nube, persistencia de datos local, gestión de carrito, favoritos, historial y soporte multi-rol (Cliente y Administrador) con modo oscuro/claro global.


---


## Características 


- Autenticación Segura Firebase : Control de acceso e inicio de sesión para usuarios y administradores.
- Persistencia Local Room Database: Gestión sin conexión del catálogo, favoritos y el historial de productos visualizados
- Catálogo y Filtros Avanzados: Barra de búsqueda , filtrado por categorías, ordenamiento por precio y orden alfabético.
- Carrito de Compras y Pagos: Gestión de artículos seleccionados con simulación del proceso de compra.
- Historial de Navegación: Registro automático de los productos abiertos por el usuario para un acceso rápido.
- Panel de Administrador: Herramientas de mantenimiento para sincronizar datos desde internet, limpiar caché local y visualizar métricas del sistema.
